# Todo List

A simple React todo list app built with Vite. It displays a title and a list of todos.

## Installation

1. Clone the repository:

```
   git clone https://github.com/VictorAcuna04/todo-list.git
```

2. Go into the project folder:

```
   cd todo-list
```

3. Install dependencies:

```
   npm install
```

## Run the Development Server

```
npm run dev
```

Then open http://localhost:5173 in your browser.
